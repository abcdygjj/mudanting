# 牡丹亭 · 一场可游的梦

互动叙事习作 v1.0 ｜ 改编自汤显祖《牡丹亭》｜ 一周目约 45–70 分钟

## 开始游玩

双击 `index.html`，用 Chrome 或 Edge 打开即可。无需安装、无需联网、无需构建。

如果浏览器对本地文件限制较严，也可以在本目录运行：

```
python -m http.server 8000
```

然后访问 `http://localhost:8000`。

## 操作

| 操作 | 方式 |
| --- | --- |
| 推进对白 | 点击画面，或按 `Enter` / 空格 |
| 探索 | 点击场景中的金色菱形；鼠标悬停会显示名称 |
| 选择 | 点击选项，或按数字键 `1` `2` `3` |
| 札记 | 右上「记」，四页：意象 / 曲词 / 人物 / 札记 |
| 导读 | 右上「导」，四页：故事 / 人物 / 曲词 / 典故 |
| 设置 | 右上「设」：字号、音量、减少动态、线索提示 |
| 提灯 | 第四章按 `L` 切换提灯 / 全亮；`Esc` 关闭抽屉 |
| 键盘 | `Tab` 聚焦热点，`Enter` 触发 |

## 内容规模

- 五出：游园、惊梦、寻梦、拾画、还魂
- 四景：春日花园、梦境园林、杜丽娘闺房、夜园（第五出复用梦境加黎明滤镜）
- 六位人物：杜丽娘、柳梦梅、春香、杜宝、陈最良、石道姑
- 八类玩法：自由探索、环境解谜（引光）、曲词拼合、对话选择、梦境变化、时机节奏（三笔 / 三声）、视角切换、收集
- 八段汤显祖原文、12 件意象、15 则札记、三个结局
- 所有谜题均可跳过，答错只给提示，不扣资源、不阻断主线

## 创作说明

- **画面**：四张 2048×1152 场景图按 16:9 直接应用，热点按画面重新定位；未做裁切、重采样或画面内 UI 标记。
- **立绘**：五人立绘为独立重绘的全身透明底 PNG（`fig_du / fig_liu / fig_chun / fig_bao / fig_chen.png`），沿用原设定海报的脸型、发式、服色与道具（团扇、书册、荷包、卷轴、玉带），画风与场景同为国风水墨淡彩，底色透明，可直接叠在任意场景上；对白、札记人物页共用同一套图，仅在 CSS 里控制尺寸与柔和收边。
- **画中丽娘**：`fig_du_painting.jpg` 是同一立绘的纸本装帧版，供「描画」「叫画」两处当作画作使用。
- **音乐与音效**：全部由 Web Audio 实时合成（拨弦模拟古琴、正弦加颤音模拟笛、泛音模拟磬、滤波噪声模拟水声与风声），不引用任何现有录音。
- **文本**：八段汤显祖原文单独标注出处与折目；对白、题画诗、联句为现代重写或游戏原创，游戏内明确标注「游戏原创 · 非汤显祖原文」。
- **存档**：写在浏览器 localStorage；刷新后续玩会回到本章开头，避免卡在谜题中间。

## 修改内容

- 剧本、人物、原文、札记、导读、结局：`js/data.js`（步骤词汇见文件内注释）
- 立绘：`assets/img/fig_*.png`，同名覆盖即可换人；对白尺寸与收边在 `css/game.css` 的 `.portrait-inner`，人物页缩略图在 `.person-row img`，画作版在 `.call-portrait` / `.trace-canvas`
- 颜色、字号、版式：`css/game.css` 顶部变量
- 谜题参数与提示：`js/puzzles.js`
- 场景热点坐标：`js/data.js` 中每章的 `hotspots`（按图内百分比）

## 已知限制

- 竖屏手机可以玩，但画面会裁掉左右两侧，建议横屏；进入游戏时也有提示。
- 浏览器要求先有一次点击才能出声，因此音乐在点「入园」后淡入。
- 本地直接打开时，个别浏览器可能限制 `localStorage`；此时可改用本地静态服务器。
